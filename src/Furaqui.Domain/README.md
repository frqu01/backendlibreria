# FuraquiApi.Domain

Capa de Dominio para la librería **FuraquiApi**.

Contiene las entidades puras de dominio (`CorreoApi`, `ResultadoApi`, `PaginacionApi`, etc.) y enumeraciones (`EFuraquiTipo...`) libres de dependencias de infraestructura.

## Instalación
```bash
dotnet add package FuraquiApi.Domain
```
